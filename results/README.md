# results folder

This folder contains the outputs from PUGS detection workflow. It contains model prediction results of each model experiment setup as listed in [Model experiment setup](/models/README.md#model-experiment-setup).

It contains four sub-folders: 
1. `whole_area_prediction` folder

    Contains the model prediction outputs generated by different model experiments setup.
    
    Naming convention is `pred_v<number>.geotiff`. `number` is the number corresponds to the model experiment version according to [Model experiment setup](/models/README.md#model-experiment-setup).

2. `clipped_prediction` folder
    
    Contains the model prediction outputs generated by different model experiments setup. The outputs are clipped to Dresden administrative boundary. 
    
    Naming convention is `clipped_pred_v<number>.geotiff`. `number` is the number corresponds to the model experiment version according to [Model experiment setup](/models/README.md#model-experiment-setup).

3. `fn_maps` folder

    Contains False Negative (FN) maps for visual inspection (areas where the model missed PUGS present in the ground truth).

    Naming convention is `fn_area_v<number>.geotiff`. `number` is the number corresponds to the model experiment version according to [Model experiment setup](/models/README.md#model-experiment-setup).

4. `fp_maps` folder

    Contains False Positive (FP) maps for visual inspection (areas where the model predicted PUGS, but they are not presented in the ground truth).

    Naming convention is `fp_area_v<number>.geotiff`. `number` is the number corresponds to the model experiment version according to [Model experiment setup](/models/README.md#model-experiment-setup).
