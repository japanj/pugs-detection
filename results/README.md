# results folder

This folder contains the outputs from PUGS detection workflow. It contains model prediction results of each model experiment setup as listed in [Model experiment setup](/models/README.md#model-experiment-setup).

It contains three sub-folders: 
1. `whole_area_prediction` folder

    Contains the model prediction outputs generated by different model experiments setup.
    
    Naming convention is `pred_v<number>.geotiff`. Number is the number of model experiments version according to [Model experiment setup](/models/README.md#model-experiment-setup).

2. `clipped_prediction` folder
    
    Contains the model prediction outputs generated by different model experiments setup. The outputs are clipped to Dresden administrative boundary. 
    
    Naming convention is `clipped_pred_v<number>.geotiff`. Number is the number of model experiments version according to [Model experiment setup](/models/README.md#model-experiment-setup).

3. `fn_fp_maps` folder

    Contains False Negative (FN) and False Positive (FP) maps for visual inspection and further analysis

    Naming convention is `fn_area_v<number>.geotiff` and `fp_area_v<number>.geotiff`. Number is the number of model experiments version according to [Model experiment setup](/models/README.md#model-experiment-setup).
