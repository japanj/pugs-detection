OSM data acquisition notebook¶

Description

This notebook downloads OpenStreetMap(OSM) data via osmnx library. These data are used for creating public urban green spaces (PUGS) mask to feed as an input to deep learning model in later step.

The data within the specific bounding box are downloaded from the below tag lists:

Data OSM tag(key) OSM tag(value)
Green space related landuse allotments, forest, grass, greenfield, meadow, orchard, recreation_ground, village_green, vineyard, cemetery
leisure garden, golf_course, nature_reserve, park, pitch, playground
nature wood, scrub, health, grassland, wetland
tourism camp_site, picnic_site, caravan_site, zoo
Point of Interest (POI) amenity bench, waste_basket
leisure picnic_table, playground
tourism viewpoint

For footpath network, it is downloaded from osmnx by using graph_from_bbox function (network_type='walk')

footpath_network = ox.graph_from_bbox(city_bbox, network_type='walk')

Input file(s)

There is no required input files.

Output file(s)

8 files

  • LULC related to green spaces from landuse tag (green_landuse_area_dresden.geojson)
  • LULC related to green spaces from leisure tag (green_leisure_area_dresden.geojson)
  • LULC related to green spaces from natural tag (green_natural_area_dresden.geojson)
  • LULC related to green spaces from campsite tag (green_campsite_area_dresden.geojson)
  • Location of POI from amenity tag (poi_amenity_dresden.geojson)
  • Location of POI from leisure tag (poi_leisure_dresden.geojson)
  • Location of POI from viewpoint tag (poi_viewpoint_dresden.geojson)
  • Footpath network (footpath_network_edges.geojson)

LULC = Land use/Land cover

Requirements/Dependencies

This notebook doesn't have dependency with other notebooks.

# If it contains non-public access, we will assign non-public value
for row in footpath_edges.itertuples():
    if isinstance(row.access, list):
        if (
            ("yes" not in row.access)
            | ("permissive" not in row.access)
            | ("public" in row.access)
        ):
            footpath_edges.at[row.Index, "access"] = "private"
        else:
            footpath_edges.at[row.Index, "access"] = "public"
